
**2) المكونات التفصيلية:**

### A) Header Bar
- Logo + اسم المنصة
- Symbol Selector (BTC/USDT, ETH/USDT, BNB/USDT, SOL/USDT)
- Wallet Balance (USDT + NEXUS)
- Subscription Status Badge (يرمز للخطة)
- زر Dashboard

### B) Order Book (العمود الأيسر)
- قائمة Bids (أخضر) و Asks (أحمر)
- كل صف: السعر | الحجم | الإجمالي
- شريط عمق مرئي (depth bar)
- Spread في المنتصف
- آخر سعر (mark price)
- يتحدث كل 500ms عبر WebSocket

### C) Main Chart (المنتصف)
- **استخدم TradingView Lightweight Charts** (مجاني، خفيف)
- Timeframes: 1m / 5m / 15m / 1h / 4h / 1D
- Candlesticks + Volume
- Overlays: EMA20, EMA50, Bollinger Bands
- رسم تلقائي للإشارات (markers على الشارت):
  - 🟢 BUY markers
  - 🔴 SELL markers
  - كل marker يحمل tooltip مع رقم الإشارة + hash
- زر "Add Indicator" (اختياري للتوسع)

### D) Signal Feed (تحت الشارت)
- قائمة آخر 20 إشارة
- كل إشارة تعرض:
  - Symbol + Action (BUY/SELL)
  - Entry price + Timestamp
  - AI confidence %
  - Liquidity status (STRONG_BUY_WALL / STRONG_SELL_WALL)
  - **رابط BscScan للـ tx_hash** (يؤكد أنها مسجلة on-chain)
  - حالة التنفيذ (Pending / Filled / Closed + PnL)
- تحديث فوري عبر WebSocket
- فلتر: All / Buy / Sell / Profitable / Unprofitable

### E) Trade Panel (العمود الأيمن)
- Buy / Sell tabs
- Amount input (USD or asset)
- Percentage buttons (25% / 50% / 75% / 100%)
- Order Type: Market / Limit
- Limit price (if Limit)
- TP/SL inputs (اختياري)
- **زر EXECUTE** (يستدعي Binance API عبر trader.py)
- **Auto-Trade Toggle** (يُفعّل التنفيذ التلقائي للإشارات)
  - Status: ON/OFF
  - Risk per trade %
  - Max open positions
- Balance display
- Estimated fees

### F) Open Positions Table
- كل صف يمثل صفقة مفتوحة:
  - Symbol | Side | Entry | Current | Size | PnL ($ + %) | TP | SL
  - زر Close (يغلق فوراً)
  - زر Modify (تعديل TP/SL)
  - Progress bar يوضح قرب السعر من TP/SL
- يتحدث كل ثانية
- **PnL color**: أخضر > 0، أحمر < 0
- إجمالي PnL أسفل الجدول

### G) Trade History Table
- كل الصفقات المغلقة
- Symbol | Side | Entry | Exit | PnL | Duration | On-chain link
- فلترة بالتاريخ والنتيجة
- تصدير CSV

### H) Performance Panel
- Win Rate %
- Total Trades
- Total PnL ($ و %)
- Average Win / Average Loss
- Max Drawdown
- Sharpe Ratio
- **رسم منحنى Equity** (خط يوضح نمو رأس المال)
- فلترة: 7d / 30d / 90d / All-time

### I) Stats Bar (أسفل الشاشة)
- تاريخ آخر إشارة
- آخر hash on-chain
- حالة الاتصال (Binance / BSC / WebSocket)
- Latency

## 🌐 Backend — إضافات جديدة

### backend/websocket_server.py
- Flask-SocketIO أو `websockets` library
- بث مباشر لكل:
  - Order book updates
  - آخر سعر
  - إشارات جديدة
  - تحديثات الصفقات المفتوحة
  - إشعارات الاشتراكات
- Events:
  - `price_update` (كل 500ms)
  - `orderbook_update`
  - `new_signal`
  - `position_update`
  - `trade_closed`

### backend/signals_api.py
- `GET /api/signals?limit=50` — آخر الإشارات
- `GET /api/signals/:id` — تفاصيل إشارة
- `GET /api/performance?period=30d` — إحصائيات الأداء
- `GET /api/positions` — الصفقات المفتوحة
- `GET /api/history?limit=100` — سجل الصفقات
- `POST /api/trade` — تنفيذ صفقة يدوية
- `POST /api/auto-trade` — تفعيل/إلغاء التنفيذ التلقائي

### bot/position_manager.py
- `open_position(symbol, side, size, entry, tp, sl)` — يفتح صفقة
- `close_position(position_id, exit_price)` — يغلق ويسجل PnL
- `update_trailing_stop(position_id)` — يحدّث SL تلقائياً
- `check_tp_sl()` — loop يفحص كل صفقة إذا وصلت TP/SL
- `get_open_positions()` — يعيد كل الصفقات المفتوحة

### bot/performance_tracker.py
- `calculate_win_rate()` — نسبة الصفقات الرابحة
- `calculate_roi(period)` — العائد على الاستثمار
- `calculate_max_drawdown()` — أقصى انخفاض
- `calculate_sharpe_ratio()` — نسبة شارب
- `get_equity_curve(period)` — نقاط منحنى رأس المال
- `get_stats_summary()` — قاموس بكل الإحصائيات

## 🎨 Frontend — terminal.js و charts.js

### terminal.js
- `initChart()` — يهيئ TradingView Lightweight Charts
- `loadCandles(symbol, timeframe)` — يجلب OHLCV من Binance
- `subscribePriceUpdates()` — WebSocket للأسعار
- `subscribeOrderbook()` — WebSocket للـ orderbook
- `subscribeSignals()` — WebSocket للإشارات الجديدة
- `renderSignalMarkers()` — يرسم الإشارات على الشارت
- `renderOrderBook(data)` — يحدث الـ order book
- `renderPositions()` — يحدث جدول الصفقات
- `renderPerformance()` — يحدث لوحة الأداء
- `executeTrade(side, amount, type, price)` — ينفذ صفقة
- `toggleAutoTrade(enabled)` — يفعّل/يلغي التنفيذ التلقائي
- `exportHistory()` — تصدير CSV

### charts.js
- `createChart(container, options)` — ينشئ chart instance
- `addCandlestickSeries(data)` — يضيف شموع
- `addLineSeries(data, color)` — يضيف خط (EMA)
- `addMarkers(markers)` — يضيف علامات الإشارات
- `addVolumeHistogram(data)` — يضيف الفوليوم
- `updatePrice(lastCandle)` — تحديث لحظي
- `addBollingerBands(data)` — Bollinger Bands
